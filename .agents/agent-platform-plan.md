# 最终计划：内置 Agent 会话平台 + 多模态 LLM OCR

## 0. 范围与取代关系

**新建**：内置 agent 会话平台（F# 纯函数核心 + `.fsx` 工作流 + 宿主会话服务 + 聊天标签页）、内置「全文翻译」工作流、多模态 LLM OCR（LLMTornado）、MCP `runs/` + `workflows/` + `send`。

| 原需求 | 最终方案 | 状态 |
|---|---|---|
| LLM OCR + LLM 设置 + 目标语言 + 滑动窗口 | 保留（滑动窗口成为翻译工作流脚本内逻辑，参数在设置页可调） | 沿用 |
| OCR 队列更名任务队列、显示翻译进度 | **删除**：OCR 队列原名独立保留；翻译是会话，进度在聊天页与 `runs/` | 被取代 |
| MCP `ocr`/`translate` 动词 | **改为** `runs/` 观察 + `workflows/` 发现与启动 + `send` 通信控制 | 被取代 |
| 书库右键 + 阅读顶栏翻译入口 | 改为工作流菜单入口（右键 + 菜单栏），阅读顶栏入口并入同一工作流菜单机制 | 沿用并泛化 |

## 1. 已锁定决策汇总

| # | 决策 |
|---|---|
| D1 | MCP 升级为一等人机协作接口；能力边界由用户工具开关控制（可关 `put`/`send` 回只读）；数据边界（text-only、不泄露密钥/图像/路径）为开发者不变式 |
| D2 | 每 LLM provider 单 key，走既有 `ICredentialStore` |
| D3 | 设置页表单覆盖 LLMTornado 全部 provider（数据驱动枚举） |
| D4 | 译文写回既有 box 级 `translation_boxes`（ADR 0034 存储与结构校验不变） |
| D5 | 翻译窗口 N=1 默认、物理页粒度、回填上一窗译文作连贯性锚点；窗口半径在设置页可调 |
| D6 | 目标语言在设置页设默认值；工作流启动参数可覆盖 |
| D7 | OCR 队列与 agent 会话**不共享**队列、调度器、执行状态机；`runs/` 投影不强行统一两者状态 |
| D8 | 工作流为随库保存的 `.fsx` 脚本 + 元数据；内置「全文翻译」默认锁定；脚本进程内执行、拥有宿主权限、按用户信任的本地脚本设计、不构成沙箱 |
| D9 | 会话生命周期归宿主会话服务；关标签页只移除前端；停止是独立操作 |
| D10 | 消息在 Event 边界追加、不打断在途调用；cancel 即时处理；历史只追加 |
| D11 | 运行进度/消息/token 用会话事件序号，不推进 `library_revision` |
| D12 | 会话可物理清除，不影响题录、原文、译文、OCR 成果；会话与工作流定义分别管理；同步分别控制 |

## 2. 架构总览

```
设置页 ── LLM provider/密钥/目标语言/窗口参数
     └── 工作流管理（新建/编辑/删除/锁定/菜单配置，.fsx）

菜单（书库右键 + 菜单栏）读取同一份工作流定义
   让内置agent执行「X」 → 创建 Agent Session → 立即打开聊天标签页

聊天标签页（会话列表 + 会话视图 + 消息输入）
        ↕ 状态栏通知（完成/失败）
宿主会话服务（生命周期、收件箱、Event 边界、取消、恢复、物理清除）
        ↕
F# 通用 agent loop（纯函数 step: Context -> Event -> Context * Effect list）
        ↕ 效应解释器（C#）
   ├─ LLM（LlmTornado，全部 provider，确定性前缀 + cache-first）
   ├─ 版本化脚本 API（OCR 入队、等待运行事件、进度报告等宿主原语）
   └─ MCP 文献工具（进程内 McpCommandService：fetch 原文 / put 译文）

OCR 队列（现有，独立）── 多模态 LLM OCR 适配器（直连模型）

MCP：find/fetch/put/cite/send
     patchouli://runs/        观察（OCR 与 agent 各自的运行状态/增量事件）
     patchouli://workflows/   发现工作流 + 经 send start 启动
```

## 3. 子系统设计

### 3.1 F# 通用 agent 核心（新项目 `src/Patchouli.Agent/`，F#）

- 纯函数 `step : Context -> Event -> Context * Effect list`。模型结果、工具结果、用户消息、脚本推进、取消、恢复统一进 Event 流。
- Effect/Event 判别联合**只在 F# 侧定义**，C# 解释器模式匹配消费——单一权威类型定义。
- 通用核心负责模型交互、工具调用、事件循环、历史维护；**不含任何具体业务步骤**。
- Provider 缓存不变式：历史只追加；指令/工具定义/消息稳定；新内容追加到末尾；恢复时按保存顺序重建；缓存过期只影响费用与耗时。

### 3.2 版本化脚本 API 与 `.fsx` 工作流

- 工作流元数据：稳定 ID、名称、说明、脚本入口、参数定义、适用选择范围、锁定状态、菜单位置。
- 版本化 F# API（脚本的唯一受控副作用面）：
  - 读取启动参数与选中资源（文档、页范围、语言等）
  - 追加指令 / 请求模型行动 / 调用 MCP 工具 / 等待运行事件（含宿主 OCR 完成唤醒，不轮询）/ 报告进度 / 完成或停止
- **恢复模型**：脚本仅经 API 表达副作用；执行器重放已完成步骤时复用记录结果，不重调模型或工具；任意 `.NET IO` 不在可恢复保证内；崩溃时未取结果的调用按操作类型恢复，v1 不承诺恰好一次。
- **信任模型**：`.fsx` 进程内执行、拥有宿主权限、非沙箱；第一版面向用户信任的本地脚本。设置页保存前编译检查 + 醒目权限警告 + 「从内置工作流复制」为主要创建路径。
- 会话保存**脚本快照**：工作流修改只影响后续启动，在跑会话不受影响。

### 3.3 宿主会话服务（`Patchouli.Host`）

- 拥有运行生命周期：创建、收件箱、Event 边界推进、停止、取消、恢复、清除。
- **消息追加语义**：`send` 消息先进收件箱；在下一次工具调用/效应执行前的 Event 边界按序追加进会话；**未执行的调用交回 loop 重新决策，已完成调用及结果保留在历史**；不等工作流结束、不默认中断当前调用。可撤回边界逐 effect 类型定义——`put` 进入原子提交点不可撤回，`LlmChat` 在途可取消但已耗 token 不返还。
- **取消**：明确控制事件，即时处理，不等待下一次模型推理；绕过原子提交点。
- **恢复**：启动时自动恢复「仍在运行」的会话；已停止/取消/完成的不自动启动。按记录结果续跑。
- 完成/失败经 `IHostActivityTracker` + 状态栏报告通知。

### 3.4 持久化、物理清除与同步

- **会话**：归属 Library 的辅助数据，每会话独立存储目录——消息/事件历史、启动参数、脚本快照、当前步骤与已完成结果、待处理消息与待执行调用、运行状态。运行发现记录可重建；缺失会话目录不阻止 Library 打开。**物理清除会话不影响题录、原文、译文、OCR 成果。**
- **工作流定义**：随库保存，但属用户配置，不按可重建索引处理；与会话数据分别管理。
- **同步**：两个独立开关控制会话 / 工作流是否进入 Library 快照。同步过去的历史与恢复材料**不复制运行所有权**；导入他设备会话不自动重复执行。

### 3.5 内置「全文翻译」工作流（默认锁定、加入菜单）

脚本步骤：

1. 接收文档、页范围、目标语言（缺省取设置默认，D6）。
2. 按序经 MCP `fetch` 读取每页原文；窗口语境（±N 页原文 + 上一窗译文，D5）拼入确定性前缀。
3. 明确指导 agent 完整翻译、保持 Markdown 块结构。
4. 经 MCP `put` 原子覆盖 `translations/{doc}/page-N.md`（既有结构校验生效；校验失败的错误清单作为 Event 回喂，有界自愈）。
5. 写成功推进游标、报告进度；失败有限重试、记录失败页并继续。
6. **每个新任务完整覆盖指定范围，不按旧译文状态跳过**；不加来源匹配或质量检查。

### 3.6 多模态 LLM OCR（现有队列，直连）

- 实现 `MultimodalLlmOcrAdapter.RunPageAsync`（现为占位）：渲染页/区域图 → vision 调用 → 归一化为 `OcrDocumentTreeCandidate` → 统一 import/commit，禁止直写 `document_boxes`。
- 失败分类进 `OcrRetryPolicy`；环境检查/预设校验改为真实校验 provider+key+model。
- 不 agent 化；OCR 队列 UI、调度、活动跟踪原样保留。

### 3.7 设置页

- **「LLM 与翻译」分组**（新增 `LlmSettingsViewModel`）：全部 provider 表单（数据驱动枚举，每 provider 单 key + baseUrl + model + Azure subscription/deployment）、OCR 默认 provider/model、翻译默认 provider/model、目标语言、翻译窗口半径 N 与回填开关。
- **工作流管理**：列表、新建（从内置复制）、编辑（编译检查）、删除、锁定、菜单配置。内置「全文翻译」锁定期间禁止修改/删除。

### 3.8 UI

- **聊天标签页**：会话列表（活跃/历史，重开会话）+ 会话视图（消息流、工具/进度事件）+ 消息输入（`send` message，显示「已加入，将在当前步骤完成后生效」）+ 停止/恢复操作。关标签页只移除前端。
- **菜单**：所有加入菜单的工作流显示为 **让内置agent执行「工作流名」**，点击后立即启动会话并打开聊天标签页；书库右键与菜单栏读同一定义；菜单栏可**手动唤起聊天标签页**（不启动任何会话）。
- **状态栏通知**：会话完成/失败显式通知。
- 顶部菜单原「OCR」组保留原名；OCR 队列看板不变。

### 3.9 MCP（`find`/`fetch`/`put`/`cite`/`send`）

新增两个 VFS 根（根发现变为 6 目录 + 1 file）：

```
patchouli://runs/
patchouli://runs/ocr/{task-id}/status
patchouli://runs/agent/{session-id}/status
patchouli://runs/agent/{session-id}/events     ← 单调序号，增量读取
patchouli://workflows/
patchouli://workflows/{workflow-id}           ← 元数据 + 参数定义，可读
```

- `runs/`：`find/fetch` 提供列表、状态、增量事件；OCR 与 agent 各自状态，不统一投影。`runs/` 是 VFS 中首个易失运行时资源——契约明确其不进快照、不可 `put`、不属 canonical 资源。
- `workflows/`：agent 发现可用工作流及其参数模式。
- **`send`**（新动词，`readOnlyHint=false`，接入工具开关）：类型化指令——
  - `start`：`workflow` URI + 参数 → 创建会话，返回 `runs/agent/{session-id}` URI；
  - `message`：给运行中 agent 补充要求；
  - `cancel`：停止运行；`resume`：续跑已停止/中断会话。
  - 响应区分**已接收/已处理**；消息 ID 去重防重试重复追加。
- 数据边界：以上均不返回图像/路径/密钥；`put`/`send` 可被用户关闭回到只读（D1）。
- CLI 同步：`patchouli-cli` 增 `send` 命令，薄客户端映射同一请求。

## 5. 验收标准

**核心验收**：
1. OCR 与会话独立运行，互不阻塞；
2. 关闭聊天标签页后会话继续执行，可重开；
3. `send` 消息在下一效应边界生效并实际参与下一步决策；
4. 会话历史只追加（前缀缓存稳定）；
5. 修改工作流不改变正在执行的会话（脚本快照）；
6. 重启后能续跑（按记录结果恢复，不重调已完成的调用）；
7. 物理清除 session 后文献库正常打开与使用。

**补充验收**：
8. 内置翻译工作流默认锁定不可改/删；新任务完整覆盖指定范围；
9. 译文经 `put` 结构校验与原子写入；失败页记录并继续，结束有摘要；
10. 菜单工作流点击后立即打开聊天标签页；状态栏有完成/失败通知；
11. `runs/` 事件按单调序号增量读取；`send` 区分已接收/已处理、消息 ID 去重；
12. 关闭 `put`/`send` 工具后 MCP 回到只读（D1）；任何路径不泄露密钥/图像/路径；
13. 会话/工作流同步开关独立；导入他设备会话不自动执行；
14. LLM OCR 输出只经 `OcrDocumentTreeCandidate` 统一 import/commit。

**工程纪律**：每阶段非文档改动跑 `scripts/cleanup-code.ps1` 与 `scripts/inspect-code.ps1`；F# 项目纳入构建后需验证脚本对 `.fs`/`.fsx` 的覆盖。

## 7. 主要风险与缓解

| 风险 | 缓解 |
|---|---|
| `FSharp.Compiler.Service` 体积与首次编译延迟（挤压 V3-T4 包预算） | S2 单独验收；内置工作流可编译进程序集作为兜底，`.fsx` 失败不影响翻译交付 |
| `.fsx` 完整宿主权限的信任面 | 醒目权限警告、保存前编译检查、从内置复制为唯一推荐路径、内置锁定 |
| 可撤回效应边界被特判腐蚀 | S0 逐 effect 类型写清撤回规则；`put` 原子提交点不可撤回 |
| 全量重译 token 成本 | 结束摘要显示调用量/成本估算；前缀缓存降低单价 |
| 会话可发现性 | 会话列表内置于聊天标签页 + 状态栏通知（已纳入方案） |
| 会话数据膨胀 | 独立目录 + 物理清除 + 同步开关 |
