# UI 配色与双模式系统

本文档说明 Patchouli.UI 的配色方案与明暗模式规范。

## 1. 明暗模式 (ThemeMode)

系统设置「外观与阅读」支持三种模式选项：
- **跟随系统 (`system`, 默认值)**: 启动和运行时自动响应操作系统明暗模式变化。
- **浅色 (`light`)**: 强制应用浅色主题，不受操作系统影响。
- **深色 (`dark`)**: 强制应用深色主题，不受操作系统影响。

模式偏好持久化在用户配置 `UiPreferences.ThemeMode`，Fluent `ThemeVariant` 与自定义调色板资源由同一有效模式统一驱动。

## 2. 双模式配色契约 (UiColorPalette)

每套配色方案 (`UiColorPalette`) 均同时具备浅色 (`LightColors`) 与深色 (`DarkColors`) 两种模式：
- 用户切换明暗模式时，保持当前选中的配色方案 ID 不变，自动选用该方案对应的模式集合。
- 优先使用方案明确声明的颜色集合；内置 Radix 配色方案均由 `tools/palette-generator/generate_palettes.py` 从 `@radix-ui/colors` 生成对应的 12 阶浅色与深色色彩。

## 3. 缺失模式自动反相规则

若外部或自定义配色方案仅声明了单侧模式（仅有浅色或仅有深色），系统通过可预测的编码 sRGB 字节反相算法（不先转换为线性光）自动补齐缺失模式：
- 反相基线公式：
  $$\begin{aligned}
  R' &= 255 - R \\
  G' &= 255 - G \\
  B' &= 255 - B
  \end{aligned}$$
- **保留 Alpha 通道**：`A' = A`。
- **作用于全部颜色键**：对配色集合内的全部 key（包括背景层级、正文、次要文字、强调色、边框、错误态、以及未知的自定义 key）统一处理。
- **幂等与无漂移**：始终由原始显式定义的颜色单向生成缺失模式，多次切换不发生色彩累计漂移。
- **范围限制**：自动反相仅作用于 UI 配色方案及控件主题资源，不对文献内容（PDF 页面、图片、OCR 扫描图等原始内容）做整窗或像素反色。

## 4. 生成与可读性

配色数据和语义映射由 tools/palette-generator/generate_palettes.py 维护；先修改 generator 再重生成，禁止手写生成文件。按钮文字优先保留已有前景；若与 PrimaryContainerColor 的 WCAG 相对亮度对比度低于 4.5:1，generator 生成的解析器选择对比更高的黑色或白色。原始 Radix 色阶保持不变。

## 5. 深色背景与状态栏

深色模式的大面积背景使用当前主色系的 Radix dark 1–5 色阶，分隔线使用第 6 阶；不再使用配对中性色作为背景。深色状态栏的 InverseSurfaceColor 等于当前 PrimaryColor，前景按既有可读性规则选取。浅色模式的所有颜色及暗色状态栏保持原样。缺失模式的反相算法不变。
