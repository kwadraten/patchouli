# Use MinerU As First Product OCR Provider

Status: proposed

The first product OCR/layout path should use MinerU precise parsing, while Tesseract remains a temporary alpha/developer surface unless explicitly retained for diagnostics. MinerU better matches the product need for OCR plus structured layout import into LayoutRevisions and SearchUnits.

**Consequences**

The product UI and first-run flow should stop presenting Tesseract as the primary OCR path once the MinerU workflow lands.
